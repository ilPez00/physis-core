- Apache-2.0 applies to the files and releases explicitly distributed under
  it, including all history of this repository up to its retirement commit.
  Rights already granted to previously distributed copies are **not revoked**
  by any later change of visibility, license, or archival status.
- The Apache-2.0 license on historical source code does not automatically
  grant access to private repositories, hosted services, the `Physis` name
  beyond nominative use, future proprietary modules, or confidential
  integrations.
- Future projects — including any successor research releases and commercial
  products — may use different licenses. Those licenses will be stated in
  those projects, not here.
- Apache-2.0 already permits commercial use of the licensed code. No separate
  "commercial license" is or was required to use the Apache-2.0 code
  commercially. Historical documents in this repository that suggest otherwise
  (notably `STRIPE_LICENSE_GUIDE.md` and `PLANNING.md` §4) are superseded by
  this file and are retained only as history.
